# Society

Мини-социальная площадка, ранний прототип.

## Сейчас
- Адаптивный интерфейс (desktop/mobile)
- Лента демо-публикаций
- Создание постов в локальном браузере
- Комментарии к постам
- Лайки
- Сохранённые посты
- GitHub Pages workflow

> В текущей версии данные хранятся в localStorage только в текущем браузере. Это UI-прототип, не общая соцсеть. Авторизация GitHub и облачная БД ещё не подключены.

## Публикация
GitHub Actions автоматически публикует сайт из ветки `main`. После включения Pages (Settings → Pages → Build and deployment → GitHub Actions), сайт появится по адресу:
`https://nikita83ussr.github.io/Society/`
